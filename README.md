# 🚀 Portfólio Dev — Neon Dark Theme

Portfólio profissional moderno com tema futurista preto + azul neon.

## 🛠️ Tech Stack

- **React 18** — UI Library
- **Vite** — Build tool ultrarrápido
- **Tailwind CSS** — Utility-first CSS
- **Framer Motion** — Animações fluidas
- **React Icons** — Ícones profissionais

## ⚡ Setup

```bash
# 1. Instalar dependências
npm install

# 2. Rodar em dev
npm run dev

# 3. Build para produção
npm run build

# 4. Preview do build
npm run preview
```

## ✏️ Personalização

1. **Seu nome** → `src/components/Hero.jsx` — substitua `SEU NOME AQUI`
2. **Links de contato** → `src/components/Contato.jsx` — atualize `href` dos contatos
3. **GitHub** → troque `@seuuser` pelo seu handle
4. **LinkedIn** → troque `/in/seuperfil` pelo seu perfil
5. **WhatsApp** → troque o número pelo seu
6. **Email** → troque `seu@email.com` pelo seu email
7. **Links dos projetos** → `src/components/Projetos.jsx` — adicione URLs reais
